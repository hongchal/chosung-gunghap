## Executive Summary (4관점 요약)

| 관점 | 내용 |
|---|---|
| **Problem (문제)** | 토스 유저 20-30대는 친구와 30초 안에 공유할 수 있는 가벼운 콘텐츠를 매일 찾지만, 기존 운세앱은 다운로드 마찰·과한 결제·진입 장벽이 높아 즉시 소비·즉시 공유에 부적합하다. |
| **Solution (해결)** | 단 2화면, 단 2기능. 이름 2개 입력 → 궁합 보기 → 공유하기. 결제(990원)는 "공유하기" 버튼 안에 자연스럽게 녹아 있어 사용자는 결제를 기능으로 인지하지 않는다. |
| **Function · UX · Effect** | **입력 1탭 → 결과 0.5초 → 공유 1탭.** UX는 토스 디자인 시스템(TDS) 2화면 전용 구조. IAP 전환율 목표 5% (단순함이 결제 마찰을 줄임). 출시 1개월 내 MAU 5만 · 월 매출 150만원 달성. |
| **Core Value (핵심 가치)** | "30초짜리 대화 시작 트리거" — 토스 디자인 철학 그 자체: 빠르다 · 쉽다 · 편하다. 결제 990원은 카페 음료 1/5 가격, 토스 머니로 마찰 0. |

## Context Anchor

| 차원 | 내용 |
|---|---|
| **WHY** | 토스 미니앱 시장(2,053개 미니앱, MAU 2,900만)의 무료 진입로를 활용해 1인 개발자가 월 100-500만원 수익 라인 구축. 한국 운세 시장 1.4조원 중 "초저가·초고빈도·바이럴 공유" 세그먼트 점유. |
| **WHO** | 1차: 토스 활성 이용자 중 친구와 콘텐츠 공유를 즐기는 20-30대 여성 (60%) + 10-20대 학생 (30%) + 직장인 친구 모임 (10%). |
| **RISK** | (1) 앱인토스 검수에서 "점술/사행성" 판정 → "재미용 알고리즘" 명시 + 면책 문구. (2) 사업자 등록 1-3일 대기. (3) 단 2기능 구조로 재방문 콘텐츠가 부족할 경우 D7 retention 하락. (4) IAP 전환율 1% 미만 시 BEP 미달. |
| **SUCCESS** | 출시 30일: MAU 5만 / 결제자 2,500명 / IAP 전환율 5% / ARPPU 990원 / 월 매출 250만원. 90일: MAU 15만 / 월 매출 500만원 / D7 retention 15%. |
| **SCOPE** | **In**: 한글 이름 기반 5차원 알고리즘, 결과 화면 (무료+유료), 단일 IAP 990원, 공유 카드 생성 (9:16), 카톡/인스타 공유, TDS 컴포넌트. **Out (v1)**: 로그인/회원가입, 결과 히스토리, 사주/생년월일 기반 정통 궁합, 상담사 매칭, 다국어. |

## 제품 구조 (2화면 원칙)

```
[ 화면 1: 입력 ]
  - 내 이름 (텍스트 필드)
  - 친구 이름 (텍스트 필드)
  - "궁합 보기" 버튼 (Primary CTA)

       ↓ (0.5초 이내)

[ 화면 2: 결과 + 공유 ]
  ─── 무료 영역 (즉시 노출) ─────────────────
    - 종합 점수 (0-100)
    - 한 줄 코멘트
    - 오행 상성 라벨 ("불×물 = 격렬한 케미")
  ─── 유료 영역 (블러 처리) ─────────────────
    - 분야별 점수 4개 (연애/우정/케미/일상)
    - 관계 시나리오 텍스트 (3-4문장)
  ──────────────────────────────────────────
  단 하나의 CTA: [ 공유하기 ] 버튼
    → IAP 결제창 (990원)
    → 결제 완료:
        • 블러 해제 + 풀 결과 공개
        • 고화질 공유 카드 자동 생성 (9:16)
        • 카톡/인스타 공유 다이얼로그 호출
```

**핵심 인사이트**: 사용자 인지 동작은 "보기 → 공유" 2개뿐. 결제·블러 해제·카드 생성은 "공유하기" 한 버튼 안에 묶여 있어 결제를 기능으로 느끼지 않는다.

## 1. Problem & Opportunity

### 1.1 5-Step Discovery Chain (Teresa Torres)

#### Step 1 — Brainstorm (가설 다이버전스)

- 사람들은 "친구와 톡방에서 가볍게 던질 콘텐츠"를 매일 찾는다
- MBTI 인기는 식어가지만 "관계 콘텐츠" 수요는 유지된다
- 토스 안에 머무는 시간이 길어진 유저는 "무언가 누르고 싶음" 상태가 자주 발생한다
- 결제는 비싸지 않으면 1,000원 미만에서 즉흥적으로 발생한다
- 이름 2개는 누구나 바로 입력할 수 있어 진입 마찰이 0에 가깝다

#### Step 2 — Assumptions (가설 명시)

| ID | 가설 | 신뢰도 |
|---|---|---|
| A1 | 토스 유저는 미니앱 홈에서 "심심풀이 콘텐츠" 카테고리에 진입한다 | High (점신/봉봉 사례) |
| A2 | 결과를 본 사람의 5% 이상이 공유 카드를 위해 990원을 결제할 의사가 있다 | Medium |
| A3 | 공유 카드를 받은 친구의 30%가 다시 진입한다 (바이럴 K-factor) | Medium |
| A4 | "이름 궁합"이 "초성 궁합"보다 콘텐츠 깊이가 충분하고 더 자연스럽다 | High (5차원 알고리즘) |
| A5 | 1인 개발자가 6주 안에 검수 통과까지 가능하다 | High (코심 2주, 디스팟 5일 사례) |

#### Step 3 — Prioritize (Impact × Risk)

| 가설 | Impact | Risk | 우선순위 |
|---|---|---|---|
| A2 (결제 전환율 5%) | 매우 높음 | 매우 높음 | **1순위 — 검증 필수** |
| A3 (바이럴 계수) | 매우 높음 | 중간 | 2순위 |
| A4 (이름 궁합 깊이) | 높음 | 낮음 | 3순위 |
| A1 (유입) | 중간 | 낮음 | 4순위 |
| A5 (개발 일정) | 중간 | 낮음 | 5순위 |

#### Step 4 — Experiments (검증 실험)

| # | 실험명 | 방식 | 측정지표 | 기간 |
|---|---|---|---|---|
| E1 | Painted Door — 결제 의향 | 무료 결과 후 "공유하기 (990원)" 버튼 클릭 비율 측정 (실제 결제 미연결, 사전 등록 폼) | 클릭률 5% 이상 | 1주 |
| E2 | Wizard of Oz — 공유 카드 | 수동 카드 생성 후 카톡 공유율 측정 | 결제자의 70% 이상 공유 | 1주 |
| E3 | Concierge — 가격 민감도 | A/B 테스트로 590원 vs 990원 전환율 측정 | ARPPU × 전환율 최대값 도출 | 출시 후 2주 |

#### Step 5 — Opportunity Solution Tree (OST)

```
[Desired Outcome]

  │
  └─ [Opportunity 4] "운세 콘텐츠지만 사행성이 아닌 재미용임을 명확히"
```

#### Moments of Truth (앱을 떠올릴 5가지 순간)

1. **톡방에 정적이 흐를 때** — "야 우리 이름 궁합 한 번 볼래?" (가장 강력)
2. **소개팅 전후** — 상대 이름을 알게 됐을 때 "어디 보자..."
3. **친구 결혼 소식 들었을 때** — "둘이 잘 어울려?" 라며 톡방 공유
4. **인스타 스토리에 #이름궁합 트렌드 봤을 때** — 따라하기
5. **토스 미니앱 홈 둘러볼 때** — 무료니까 한 번 눌러봄

## 2. Target Users (페르소나)

### 2.1 Persona 1 — "공유광 대학생 지윤" (Primary, 50%)

- **데모**: 23세, 여, 수도권 대학 3학년, 토스 사용 빈도 일 5회
- **JTBD**: "**친구 톡방이 심심할 때**, 나는 **3초만에 웃길 만한 콘텐츠**를 던지고 싶다. **그래야** 톡방의 분위기 메이커로 인식된다."
- **Pain**: MBTI는 식상함, 사주는 너무 진지함, 적당한 콘텐츠가 없음
- **Gain**: 친구가 "ㅋㅋㅋ" 반응 보내는 순간
- **WTP**: 990원/회 × 월 2-3회

### 2.2 Persona 2 — "주말 톡방 직장인 민호" (Secondary, 30%)

- **데모**: 31세, 남, 직장인 5년차, 친구 모임 그룹챗 활발
- **JTBD**: "**친구들이랑 술자리 잡을 때**, 나는 **분위기를 띄울 짧은 게임**이 필요하다. **그래야** 어색한 새 멤버도 자연스럽게 섞일 수 있다."
- **Pain**: 매번 같은 게임(MBTI, 밸런스게임)에 지침
- **Gain**: 새로운 화제거리, 짝 만들기 코드로 활용
- **WTP**: 990원/회 × 모임당 5회 = 4,950원/모임

### 2.3 Persona 3 — "트렌드 추종 고등학생 서연" (Tertiary, 20%)

- **데모**: 17세, 여, 고2, 토스 청소년 인증 사용
- **JTBD**: "**친구가 SNS에 #이름궁합 올렸을 때**, 나는 **나도 똑같은 카드를 만들어** 인스타 스토리에 올리고 싶다. **그래야** 유행에 뒤처지지 않는다."
- **Pain**: 학생이라 자주 결제 못함, 부모 결제 거부감
- **WTP**: 990원/회 × 월 1-2회 (트렌드 폭발 시 추가)

## 3. Solution & Value Proposition

### 3.1 JTBD 6-Part Value Proposition

| Part | 내용 |
|---|---|
| **1. For (대상)** | 친구와의 톡방에서 즉시 던질 콘텐츠를 매일 찾는 토스 활성 사용자 20-30대 |
| **2. Who (특징)** | MBTI는 식상하고 사주는 부담스럽지만 "재미용" 운세는 좋아하며 990원 정도는 즉흥 결제하는 사람 |
| **3. The (제품)** | 이름궁합 미니앱 |
| **4. Is a (카테고리)** | 한글 이름 기반 5차원 마이크로 페이먼트형 궁합 콘텐츠 |
| **5. That (혜택)** | 다운로드 없이 30초 안에 친구와 공유 가능한 궁합 카드를 만들어준다 |
| **6. Unlike (차별점)** | 점신/포스텔러처럼 무거운 사주앱이 아니라, 봉봉처럼 가볍지만 토스 안에 있어 결제·공유 마찰이 거의 0이다 |

### 3.2 알고리즘: 5차원 이름 분석

이름 2개에서 추출하는 5개 차원으로 콘텐츠 깊이를 확보한다. LLM 호출 없음, 변수 조합형 템플릿으로 비용 0원, 검수 안정성 확보.

| 차원 | 계산 방식 | 출력 |
|---|---|---|
| **획수법** | 자모 획수 합산 → 인접수 합산 → 백분율 점수 | 종합 점수 (0-100) |
| **오행 상성** | 한글 자음 오행 매핑 (목/화/토/금/수) → 상생/중립/상극 | 오행 라벨 + 한 줄 |
| **음양 균형** | 양/음 자모 비율 → 균형도 | 분야별 점수 반영 |
| **모음 조화** | 양성모음/음성모음 매칭 비율 | 분야별 점수 반영 |
| **캐릭터 유형** | 첫 글자 오행 → 4-6개 캐릭터 부여 | 관계 시나리오 텍스트 |

5차원 합산 → 단일 종합 점수 + 분야별 4점수 + 시나리오 3-4문장 자동 생성.

## 8. Risks & Mitigations (Pre-mortem)

> "출시 3개월 후 실패했다고 가정해보자. 무엇이 잘못됐을까?"

### Top 3 Critical Risks

#### Risk 1 — 검수 반려 (사행성/점술 카테고리 판정) — **Critical**

- **확률**: 30% / **영향**: 출시 1-2주 지연
- **Mitigation**: 모든 화면 "재미용 콘텐츠" 명시, "운명/예언" 표현 금지, 알고리즘 계산 방식 FAQ 공개
- **Contingency**: 반려 시 24시간 안에 디스클레이머 강화 + 재제출

#### Risk 2 — IAP 전환율 1% 미만 (BEP 미달) — **Critical**

- **확률**: 20% / **영향**: 월 매출 50만원 미만 → 사이드 프로젝트 의미 상실
- **Mitigation**: 출시 2주차 즉시 A/B 가격 테스트 (P2-03), 블러 강도 조절로 호기심 극대화
- **Contingency**: 전환율 1.5% 미만 30일 지속 시, "공유하기" UX 개선 + 290원 미니 버전 추가

#### Risk 3 — 단순 2화면 구조로 재방문률 하락 — **Important**

- **확률**: 50% / **영향**: D7 retention 5% 이하 → 바이럴 루프 끊김
- **Mitigation**: Phase 2에서 시드 변수 도입 (동일 이름이어도 요일/날짜 시드로 결과 미세 변경), "다른 친구 이름으로 보기" CTA 강화
- **Contingency**: D7 retention 5% 미만 시 시드 변수 긴급 도입 (1개월 내)

| D-15 | **개발 도구 = @ait-co/devtools** | 토스 샌드박스 앱 없이 브라우저에서 IAP/공유 전 플로우 시뮬레이션. 사업자 등록 대기 중에도 결제 흐름 100% 검증 |
| D-16 | **"토스 포인트 결제" 표현 완전 금지** | 앱인토스 IAP 정책: "현금성·환가성 상품이나 **토스 포인트와 결합해 제공하는 상품은 판매할 수 없음**". UI/마케팅/약관에 "토스 포인트로 결제" 표현 절대 사용 X. 표준 표현: "인앱 구매" 또는 "공유하기 · ₩990". 결제 수단 UI는 토스 SDK가 자동 제공 |
| D-17 | **IAP 상품 유형 = 비소모품 (non-consumable)** | "공유 잠금 해제"는 한 번 구매로 영구 적용 성격. 소모품으로 등록 시 매 공유마다 재결제 필요해서 UX 깨짐. 비소모품 + 미결 주문 복원으로 결제 후 앱 재진입 시 자동 잠금해제 |
| D-18 | **종합 점수 = 획수 피라미드법 (일반 대중 표준)** | 사용자 피드백: 일반인이 아는 "이름 궁합"은 획수 피라미드법 하나뿐(오행/음양은 사주 전문가 영역, 기대 밖). 종합 점수는 음절 획수를 번갈아 배치→인접합 %10 반복→두 자리 백분율(00→100%)로 산출. 검증값: 김철수♥이영희=57%. 오행·음양·모음·캐릭터(소리오행, 생시·한자 불필요)는 분야별 점수·라벨·시나리오의 **부가 정보**로만 활용, 종합 점수에 미반영 |
